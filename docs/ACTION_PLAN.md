## 📋 Крок 6 — Платіжна система (3-5 днів)

**Мета:** три тарифні плани, прийом оплати

### 6.1 Stripe (міжнародні платежі / діаспора)
- [ ] Створити Stripe акаунт
- [ ] Налаштувати 3 Products + Prices:
  - Екіпаж (індивідуальна) — $4.99/міс
  - Командир (сімейна) — $7.99/міс
  - Академія (спеціалісти) — $14.99/міс
- [ ] Stripe Checkout Session (серверна частина — Supabase Edge Function)
- [ ] Stripe Webhook для оновлення підписки в profiles
- [ ] Customer Portal для управління підпискою

### 6.2 LiqPay (Україна)
- [ ] Створити LiqPay акаунт (через PrivatBank)
- [ ] Інтегрувати LiqPay Checkout
- [ ] Webhook для підтвердження оплати
- [ ] Синхронізація статусу підписки з profiles таблицею

### 6.3 Paywall логіка в додатку
- [ ] Розмежувати контент за тирами: free / premium / specialist
- [ ] Free tier: 3-5 ресурсів на планету + Домашня Станція
- [ ] Premium: повний доступ до всіх планет
- [ ] Specialist: + Тренінг-Хаб з вебінарами
- [ ] UI для вибору тарифу (pricing page)
- [ ] 7-денний безкоштовний trial
- [ ] Upgrade prompts на заблокованому контенті
